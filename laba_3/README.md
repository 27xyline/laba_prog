# Генератор растровых изображений

Лабораторная работа на C++17: генерация текстовых изображений PPM P3 и PGM P2. Используется стандартная библиотека C++, сторонние графические библиотеки не нужны. Выполнен **вариант 2**: шахматная доска с диагональными узорами Трюше.

## Сборка и запуск

```sh
make
./build/raster
```

Для сборки нужен компилятор C++17 и `make`. Флаги сборки: `-std=c++17 -Wall -Wextra -Werror -pedantic`. Без `make` программу можно собрать так:

```sh
c++ -std=c++17 -Wall -Wextra -Werror -pedantic main.cpp image.cpp graphics.cpp truchet.cpp -o raster
./raster
```

Команда `make clean` удаляет папку сборки.

## Работа с программой

При запуске создаётся белый холст 512×512. В меню можно создать новый холст, последовательно добавить несколько фигур, залить замкнутую область и сохранить результат. Сохранение не очищает холст, поэтому одно изображение можно записать в оба формата. Выбор нового холста заменяет текущее изображение.

- Прямоугольник задаётся центром, размерами, цветами, толщиной и признаком заливки.
- У вложенных квадратов задаются начальная сторона, количество, шаг и два цвета. Сторона уменьшается на удвоенный шаг, а цвет линейно меняется от первого к последнему.
- Отрезок строится алгоритмом Ву со сглаживанием либо алгоритмом Брезенхема с заданной толщиной. Координаты концов могут быть дробными.
- Многоугольник рисуется замкнутым контуром. Для заливки его внутренней области используется отдельный пункт меню.
- При заливке допуск задаётся в единицах RGB 0–255 как евклидово расстояние до цвета исходного пикселя. Ноль означает точное совпадение; максимальное возможное расстояние между цветами составляет приблизительно 441,67.
- Доска заполняет весь текущий холст. Число клеток по оси не должно превышать размер изображения по этой оси. Ориентация диагонали определяется правилом `(строка * столбец) % 2`, диагонали сглаживаются алгоритмом Ву.

Например, чтобы сохранить красный прямоугольник в PPM:

```text
1
100 100
255 255 255
2
50 50
60 40
0 0 0
1
255 0 0
2
8
1
rectangle.ppm
0
```

Каждая строка соответствует одному запросу программы. Цвет вводится как три целых числа в диапазоне 0–255. Путь к файлу может содержать пробелы. При ошибке параметров программа сообщает о ней и возвращается в меню; конец ввода завершает программу.

Размер холста ограничен 16 384 пикселями по каждой оси и 16 000 000 пикселями всего, координаты фигур — диапазоном от −1 000 000 до 1 000 000, толщина — от 1 до 10 000 пикселей.

## Устройство

- `image.hpp`, `image.cpp`: `Color`, непрерывный буфер `Image`, интерфейс `IPNMExporter` и реализации `P2Exporter`, `P3Exporter`. При преобразовании в серый используется `0.299R + 0.587G + 0.114B`; длина строки Netpbm не превышает 70 символов.
- `graphics.hpp`, `graphics.cpp`: `Canvas`, интерфейс `IShape`, прямоугольники, квадраты, линии, многоугольники и нерекурсивная заливка. Доступ к пикселям проверяется, линии предварительно отсекаются границами холста.
- `truchet.hpp`, `truchet.cpp`: вариант 2 — шахматная доска с узорами Трюше.
- `main.cpp`: меню, проверка ввода и обработка исключений.

`IPNMExporter` позволяет выбирать стратегию сохранения во время работы программы. Все фигуры реализуют `IShape` и рисуются через виртуальный метод `draw`.

## Материалы для сдачи

В `examples/` находятся семь примеров, каждый в форматах PPM P3 и PGM P2. В `screenshots/` находятся PNG-изображения, использованные в отчёте. Файлы `report.typ` и `report.pdf` содержат исходник и готовый отчёт.
